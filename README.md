1. Introduction
Maternal health plays a vital role in ensuring the well-being of both the mother and the baby during
pregnancy. Early identification of maternal health risks can help healthcare professionals provide
timely treatment and reduce pregnancy-related complications. Machine learning techniques have
become an effective solution for analyzing healthcare data and supporting accurate medical decisionmaking.
The project "Maternal Risk Prediction using Machine Learning Model" aims to develop an intelligent
system that predicts the maternal health risk level using important health parameters such as Age,
Systolic Blood Pressure, Diastolic Blood Pressure, Blood Sugar (BS), Body Temperature, and Heart
Rate. In this project, a Random Forest Classifier is used as the machine learning algorithm to analyze
the maternal health dataset and classify patients into Low Risk, Mid Risk, and High Risk categories.
The system is developed using Python, Pandas, NumPy, Scikit-learn, Flask, HTML, and CSS. The
trained machine learning model is integrated with a Flask-based web application to provide fast and
reliable risk predictions. This system assists healthcare professionals in the early detection of maternal
health risks, supports better clinical decision-making, and contributes to improving maternal
healthcare management.
